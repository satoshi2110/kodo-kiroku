# プロジェクト概要（提出用の下書き）

## 名前

行動記録 ― 強度行動障害の支援記録・共有アプリ

## 一言で

家族・学校・施設が同じやり方で行動を記録し、グラフで変化を見られるスマホアプリ。記録がたまると、Claude が「その行動は何のために起きているのか」の仮説を立て、罰を使わない支援の候補を出します。

## テーマ

テーマ2「本来、誰にでも届くべきものを。」（テーマ1「あなたにしかない深さを。」の要素も含む）

## 作者について

特別支援学校の教員で、公認心理師です。応用行動分析学の研究で修士号を取りました。

学校では、行動の記録をとり、グラフで変化を確かめながら支援を考えるのが当たり前になりつつあります。けれども家庭や、ほかの施設では、記録のしかたも見立ても人によってばらばらです。専門の知識がある人がそばにいなければ、記録は「書いて終わり」になりがちです。

教員として現場で、また応用行動分析学を学んだ者として感じてきた「足りないもの」を形にしました。同じやり方で記録し、同じグラフを見て、行動のはたらきから支援を考える。その手順を、専門家がいない家庭や施設にも届けたいと考えました。

## どんな課題か

- 自傷・他害・こだわりなどが強く出る「強度行動障害」の人の支援では、行動の前後（A: 直前のこと、B: 行動、C: その後どうなったか）を記録し、行動の「はたらき（機能）」を見立てることが基本とされています。
- ところが、この記録と見立ては専門家がそばにいる人しか使えず、家族や現場の職員は「記録はしても、何が分かるのか分からない」まま毎日を過ごしがちです。
- 家庭・学校・施設で記録のしかたがばらばらで、同じグラフで変化を見ることもできません。

## 何を作ったか（ハッカソン期間中に作ったもの）

1. **10秒で残せる記録**: 行動のボタンを押すだけで +1。押し間違いは「−1」で取り消せます。続いた時間・待ち時間・強さ（3段階）も測れます。
2. **ABC記録**: 直前のこと・その後どうなったか・状況要因（睡眠不足など）を選ぶだけで書けます。選択肢はその場で足せます。
3. **インターバル記録・時間サンプリング**: 10秒ごとなどの区間で ○× を付ける、行動分析の測り方です。区間の終わりに画面の枠が光って知らせます。
4. **グラフと ABC集計**: 回数・強さ・起きた区間の割合を折れ線で表示します。記録した日に記録がなければ 0、記録していない日は線を切ります。ABC集計では、直前のこと・その後・状況要因を件数で並べます。
5. **睡眠の記録**: いつもより2時間以上短い夜は、その日の ABC記録に「睡眠不足」が自動で付きます。
6. **AI による機能分析の補助（Claude）**: ABC記録が10件以上たまると、「注目」「要求」「回避・逃避」「感覚」のどれが当てはまりそうかを、件数と根拠つきで示します。支援者が「採用」した仮説に合わせて、代わりの行動・先にできる工夫・できたときの認め方を提案します。
7. **好きなもの（強化子）リスト**: 写真とハマり度（● 5段階）、使い方と注意をチームで共有します。写真は物・活動だけで、AI にも書き出しにも入りません。
8. **場所・さかのぼって入力・行動の編集**: 記録に場所の名前が付きます（現在地は保存も送信もしません）。あとから日時を指定して記録を足し、自動の 0 を「観察していなかった」に直せます。
9. **支援計画と合意**: 標的の行動・機能の仮説・目標と達成基準・先にできる工夫・危機時の対応を書きます。変えるたびに「何を・なぜ変えたか」が消せない履歴に残り、家族が合意した日から実施中になって、グラフに「支援開始」「計画の変更」の縦線と目標の横線が入ります。
10. **支援会議メモと PDF レポート**: 会議の日のグラフとその時点の計画をメモに残します。期間と中身を選んで、会議や行政への提出用の PDF を作れます（写真と住所は入りません）。
11. **時間帯の図・できたことの一覧**: 30分ごとに起きた時間帯を色と数字で示します。「代わりの行動が3日続けて増えた」などの小さな成果を、決まった文で自動で拾います（AI は使いません）。
12. **身体拘束の記録**: 「治療や支援の方法ではない」と画面に示し、3つの要件の確認・家族への報告・あとの検討を残します。保存した記録は消せません。件数がチームで決めた目安を超えると、計画の見直しをすすめます。
13. **ABC集計の AI のまとめ**: 件数の集計だけを送り、短い文にします。機能の判断や助言の語が入ったら捨てて作り直します。
14. **CSV の書き出し**、**お試し用のサンプル**（架空の対象者と3週間分の記録・支援計画・会議メモ）。

## Claude の使い方

- **アプリの中で**: Claude API（Sonnet 5.5）を、サーバー側（Cloudflare Pages Functions）からだけ呼んでいます。API キーは画面側のコードに置いていません。
  - **構造化出力**: 結果を JSON スキーマで受け取り、カードで表示します。自由な文章のままは出しません。
  - **安全対策**:
    - 罰・弱化・嫌悪刺激・身体拘束・隔離・叱責・計画的無視は提案させません。プロンプトで禁じたうえで、出力に禁止語があれば捨てて1回だけ作り直し、それでもだめなら結果を出しません。
    - 診断・服薬・治療方針の助言をしません。体調が気になるときは「主治医に相談してください」とだけ書きます。
    - 結果は「AI による仮説」と必ず表示し、採用するかどうかは支援リーダー以上の人が決めます。
  - **仮名化**:
    - 対象者・支援者・場所の名前を「対象者」「支援者A」「場所A」に置きかえて送ります。関わった人は所属だけを送ります。
    - 写真は送りません。送る期間は直近4週間までです。
  - **使いすぎ防止**:
    - 記録が10件未満なら AI を呼びません。
    - 1人ごとの回数の上限と、API の月の支出上限を設けています。
- **作るときに**: 仕様書づくりから、画面・データ・AI 部分の実装、ブラウザでの動作確認、公開の設定まで、Claude Code と一緒に進めました。発注者（作者）が決めたことと Claude の提案を仕様書で分け、決まったことだけを作りました。

## 医療アドバイスではないこと

このアプリの AI は、診断・治療・服薬の助言をしません。行うのは、支援者が書いた記録の件数と傾向から、行動のはたらきの「仮説」を示すことと、罰を使わない支援の「候補」を出すことだけです。決めるのは支援チームです。

## 試し方

1. https://kodo-kiroku.pages.dev を開き、同意にチェックを入れて「サンプルで試す」を押します。
2. ホームで記録を押してみます。「グラフ」で変化を見ます。
3. 「チーム」→「同意と設定」で AI を「あり」にし、「AI」タブで「AI で分析する」を押します。
