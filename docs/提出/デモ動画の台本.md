# デモ動画の台本（3分・下書き）

> 撮り方: スマホで https://kodo-kiroku.pages.dev を開いて画面収録します（パソコンなら Chrome の開発者ツールでスマホ幅にする）。声はあとから重ねてもよいです。
> 撮る前に、サンプルを作り直しておくと毎回同じ画面になります（ブラウザのサイトデータを消して、もう一度「サンプルで試す」）。
> ルール: ハッカソン期間中に作ったものだけを見せます。このアプリはすべて期間中に作りました（リポジトリは 11/3 に作成）。

## 撮るときの注意

- 3分を超えないようにします。AI の待ち時間（10〜30秒）は、動画編集で縮めてもよいです。
- API キーや Cloudflare・Console の画面は映さないでください。
- 実在の人の名前や記録は映さず、サンプルだけを使います。
- 動画は YouTube（限定公開）か Loom に上げ、だれでも見られる設定にします。
