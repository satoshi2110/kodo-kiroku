## 撮るときの注意

- **場面1〜3**: 実在の子ども・家族は映しません（本人の同意が取れず、障害に関わる情報にあたるため）。子どもが頭を打ちつける演技もさせません。イラスト・影絵・黒い画面に短い文字のどれかにして、合わせて約27秒におさめます（自傷・他害・制圧・保護者）。
- **サンプルを使う**: 実在の人の名前や記録は映さず、「サンプルで試す」のデータだけを使います。サンプルは、最初の1週間がベースライン、14日前に支援開始、5日前に計画の変更で、「休憩カードを渡す」は最近になるほど増えます。
- **撮り直すとき**: ブラウザのサイトデータを消して、もう一度「サンプルで試す」を押すと、毎回同じ画面になります。
- **AI の場面**: AI を「あり」にするのは「チーム」→「同意と設定」です。結果が「（見本）」でなく本物になっているかを先に確かめます。AI の回数には上限があるので、練習で何度も押さないようにします。待ち時間（10〜30秒）は編集で縮めてかまいません。
- **身体拘束の記録**: この流れには入れていません。時間が余れば、場面7のあとに5秒ほど入れます（サンプルに記録はないので、入力の画面と3つの要件を映します）。
- **映さないもの**: API キー、Cloudflare・Supabase・Anthropic の管理画面、テスト用アカウントのメールアドレスとパスワード。
